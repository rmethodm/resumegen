Font Family Options

Which typefaces should users be able to choose from? All must work in DomPDF for PDF generation.

A

3 fonts — simple, safe (Recommended)

Keep it focused. Three distinct personalities:

  • DejaVu Sans — clean, modern sans-serif (current default)
  • DejaVu Serif — classic, formal, law/finance/academia
  • DejaVu Sans Mono — technical, engineering, developer roles

All three ship with DomPDF — zero extra setup, perfect PDF fidelity.

B

5 fonts — more variety

DejaVu Sans, DejaVu Serif, DejaVu Sans Mono (above) plus two extras loaded via Google Fonts in the live preview only (PDF falls back to DejaVu equivalents):

  • Lora — elegant serif, editorial feel
  • Raleway — geometric sans, contemporary/creative

Live preview looks great; PDF uses closest DomPDF match. Small visual discrepancy between preview and PDF.
