Quick Wins

Select everything you want to include — these are all low-effort, high-polish improvements

A

Inline resume rename

Click the resume name to edit it in place — no separate form or page. Works on both the list and the editor header.

B

Duplicate resume

One-click copy of any resume. Useful for tailoring the same base resume to different jobs. Shows up in the resume list.

C

Preview thumbnail on resume list

Show a small visual preview of each resume on the list page so users can tell their resumes apart at a glance.

D

Dashboard → editor links

Each resume row in the Analytics table on the Dashboard links directly to the editor for that resume. Currently there's no navigation from Dashboard to a specific resume.

E

Email notification for new questions

When someone submits a question via a public share link, send the resume owner an email. Currently questions land silently in the editor — easy to miss.

F

Mark all questions read

A single "Mark all read" button in the Questions panel so users don't have to click each message individually.

G

PDF syncs font sizes from editor

The PDF currently uses hardcoded sizes. Threading the font_sizes settings through to the Blade PDF view means what you see in the live preview is what you get in the PDF.

H

Welcome page redesign

The current welcome page shows generic Laravel scaffolding. Replace it with a proper landing page that explains the product and drives sign-ups.

I

Public view mobile layout

The public resume page uses a fixed 8.5in paper width that overflows on phones. Responsive layout so it reads well when a recruiter opens it on mobile.

J

Share link expiry / deactivation

Let users set an optional expiry date on share links, or toggle them active/inactive. Currently a link is live forever once created.
