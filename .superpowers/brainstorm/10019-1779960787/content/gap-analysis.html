Current App — Gap Analysis

What's built, what's missing, and what would make this competitive as a SaaS product

What's Already Strong ✓

Editor
  • Split-panel live preview
  • onBlur auto-save + beacon
  • Drag-and-drop section reorder
  • AI suggest (Claude + OpenAI)
  • Font size controls
Sharing
  • Public share links w/ tokens
  • PDF download (public + auth)
  • Contact form on public view
  • Analytics (views, DLs, msgs)
Templates
  • 4 templates (classic, modern, minimal, minimal-ruled)
  • Single-column layouts
  • Tailwind-powered preview

Priority Gaps — Templates & Visual Polish

Missing Layouts
  • Two-column with sidebar — contact/skills on left, content right (very popular)
  • Creative/bold header — large name, accent color band
  • Executive style — formal, serif-heavy
  • ATS-safe plain — no frills, maximum parsability
Missing Customization
  • Accent color picker — 6–10 preset palette swatches per template
  • Font family selector — 3–5 typeface options (Inter, Georgia, Merriweather…)
  • PDF matches preview — currently PDF uses hardcoded sizes
  • Section visibility toggles — hide/show sections without deleting

High-Value Functional Gaps (SaaS differentiators)

Productivity
  • ATS keyword scoring
  • Cover letter builder
  • Job application tracker
  • LinkedIn/PDF import
  • Duplicate resume
UX & Onboarding
  • Guided first-run wizard
  • Completeness score / tips
  • Mobile responsive editor
  • Undo/redo
  • Version history
SaaS Infra
  • Subscription / billing (Stripe)
  • Free tier limits
  • Email notifications (new msg)
  • Custom domain for public link
  • Privacy / expiry on share links

Quick Wins (low effort, high polish)

  • Rename resume inline (click-to-edit)
  • Duplicate resume button
  • Preview thumbnail on resume list
  • Dashboard: link directly to each resume editor
  • Share link label editing in-place
  • Email notification when someone submits a question
  • Mark all questions read button
  • Public view: better mobile layout
  • PDF: sync font sizes from editor settings
  • Welcome page redesign (currently shows Laravel defaults)
