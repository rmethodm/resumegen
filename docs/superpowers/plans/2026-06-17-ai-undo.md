# AI Undo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users undo any AI rewrite (summary, experience bullets, project bullets) via a toast and an inline link, without losing their original text.

**Architecture:** Pure frontend — one `useRef` stash + two state values in `Edit.tsx`. Before applying any AI result, the original value is saved under a string key. Toast auto-dismisses after 8s; inline link stays until the user edits the field or clicks undo. No backend changes.

**Tech Stack:** React 18, TypeScript, existing `Edit.tsx` state patterns

## Global Constraints

- All changes are in `resources/js/Pages/ResumeBuilder/Edit.tsx` only — no new files, no backend changes.
- Key format: `'summary'`, `'exp:{id}'`, `'proj:{id}'` — consistent across all tasks.
- Save pattern: always `setTimeout(save, 0)` after restoring state, matching existing codebase convention.
- Toast z-index: `z-50` to sit above editor chrome.
- No external toast library — inline state only.
- Run `npm run build` after all tasks to verify TypeScript compiles.

- [ ] **Step 2: Add the `showAiUndo` helper**

Directly after the `markGenerated` helper (line ~455), add:

```tsx

    setAiUndoKeys(prev => new Set(prev).add(key));
    setAiUndoToast({ key, label });
};
```

- [ ] **Step 3: Add the `handleUndo` function**

This function is generic — it reads from the ref, restores the correct piece of state, then clears the stash entry. Add it after `showAiUndo`:

```tsx
const handleUndo = (key: string) => {
    const original = prevAiValues.current.get(key);
    if (original === undefined) return;
    if (key === 'summary') {
        setSummary(original);
    } else if (key.startsWith('exp:')) {
        const id = key.slice(4);
        setExperience(prev => prev.map(e => e.id === id ? { ...e, bullets: original } : e));
    } else if (key.startsWith('proj:')) {
        const id = key.slice(5);
        setProjects(prev => prev.map(p => p.id === id ? { ...p, bullets: original } : p));
    }
    prevAiValues.current.delete(key);
    setAiUndoKeys(prev => { const s = new Set(prev); s.delete(key); return s; });
    setAiUndoToast(null);
    setTimeout(save, 0);
};
```

- [ ] **Step 4: Add the auto-dismiss useEffect**

Add this after the existing `useEffect` blocks (look for the group of effects around line 500–530):

```tsx
useEffect(() => {
    if (!aiUndoToast) return;
    const t = setTimeout(() => setAiUndoToast(null), 8000);
    return () => clearTimeout(t);
}, [aiUndoToast]);
```

- [ ] **Step 5: Add the toast JSX**

Find the closing `</div>` of the outermost editor wrapper (the last `</div>` before the component's `return` closes, around line 1290+). Add the toast immediately before it:

```tsx
{aiUndoToast && (
    <div className="fixed bottom-6 right-6 z-50 flex items-center gap-3 rounded-lg bg-[#1a1a2e] px-4 py-2.5 text-sm text-white shadow-lg">
        <span>✨ {aiUndoToast.label}</span>
        <button
            type="button"
            onClick={() => handleUndo(aiUndoToast.key)}
            className="font-medium text-[#a0a0ff] hover:text-white transition-colors"

            ↩ Undo
        </button>
        <button
            type="button"
            onClick={() => setAiUndoToast(null)}
            className="text-[#a0a0b0] hover:text-white transition-colors"
        >
            ×
        </button>
    </div>
)}
```
